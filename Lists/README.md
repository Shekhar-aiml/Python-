# Python Lists

## What is a List?

A list is a built-in Python data structure used to store an ordered collection of items. Lists are mutable, dynamic, and can store heterogeneous data types.

## Characteristics

- Ordered
- Mutable
- Dynamic
- Allows duplicates
- Supports indexing
- Supports slicing
- Supports nesting
